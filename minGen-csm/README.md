# minGen-csm — React Frontend

This is the React + Vite frontend for the **MinGen NAPOCOR CSM System**.

For full setup instructions, project overview, and documentation, see the [root README](../README.md).

## Quick Start

```bash
npm install
npm run dev
```

Runs on `http://localhost:5173/` by default.

> Requires XAMPP with Apache and MySQL running. See root README for full setup.
